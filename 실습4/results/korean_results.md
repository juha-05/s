# 실습 4 실행 결과 해설

## 핵심 결과

- 목표 2의 50 epoch 검증 기준으로 선택한 문제 유형: **regression**
- 목표 3에서 선택한 설정: **RMSprop, learning rate 0.003, 42 epoch**
- 목표 3 실제 학습 호출: **12/12회**
- 최종 테스트 정확도: **0.9625**, balanced accuracy 0.9658, unstable F1 0.9701
- 목표 2 테스트 정확도: 회귀 0.9695, 직접 분류 0.9600
- 항상 unstable을 예측하는 기준선 정확도: **0.6380**. 최종 모델은 실제 unstable 1,276개 중 59개(4.62%)를 stable로 오판정했다.
- paired bootstrap 정확도 차이(분류-회귀): -0.0095, 95% CI [-0.0185, -0.0005]

## 가설 회고

- H1: not_supported. 직접 분류의 테스트 정확도가 회귀보다 높은지로 판정했다.
- H2: not_supported. 첫 4회 대표 학습률 비교 우승 optimizer로 판정했다.
- H3: untested. Adam 0.001과 0.01을 모두 평가했을 때만 판정했다.

## 해석 주의점

`stab`은 분류 입력에 쓰면 정답과 사실상 같은 정보를 주는 누출이므로 제외했다. `p1`은 `-(p2+p3+p4)`로 복원되는 중복 정보라 제외했지만, 제거가 반드시 성능 향상을 뜻하지는 않는다. 목표 2의 MSE와 BCE 절댓값은 척도가 달라 직접 비교하지 않았다. 2-fold 표준편차는 정밀한 신뢰도 추정이 아니며, 후보 선택에도 개발 데이터를 사용했으므로 최종 일반화 평가는 테스트 결과가 담당한다. 최종 모델은 8,000개, 목표 2 모델은 6,400개로 학습했으므로 향상을 optimizer 효과만으로 돌릴 수 없다. bootstrap은 고정된 모델과 테스트 표본의 불확실성만 반영하며 학습 seed 변동은 포함하지 않는다.

## 탐색 비용과 trade-off

적응형 4+3+4+1은 optimizer 폭, 우승 optimizer의 학습률 정밀화, 상위 2개에 대한 제한적 fold 신뢰도 확인을 배분했다. 첫 단계에서 optimizer별 학습률이 하나뿐이라 다른 학습률에서 강한 optimizer를 놓칠 수 있다. 따라서 결과는 전역 최적이 아니라 **주어진 예산과 후보에서 선택한 조합**이다. 목표 3 측정 학습 시간 합은 25.3초다. 고정 예시 학습률 5개 `[0.0001,0.001,0.003,0.01,0.1]`의 전수 3-fold는 60회, 최종 재학습 포함 61회다. 호출 수 단순 비례 추정은 약 128.8초지만, 조기 종료 epoch·표본 수·CPU/GPU가 달라 실제 시간은 크게 달라질 수 있다.
