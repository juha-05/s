# 실습 4 사전 등록 계획

- 기록 시점: 2026-11-05 (Asia/Seoul), 모델 학습 전
- 상태: CSV의 앞선 점검 결과는 전달받았으나 현재 환경에서 모델 학습 결과는 아직 확인하지 않음
- 실험 계획: 사용자 전달 텍스트의 4+3+4+1 계획과 평가 규칙을 변경 없이 적용

## 문제 정의

| 항목 | 회귀 모델 A | 이진 분류 모델 B |
|---|---|---|
| 목표 | `stab` | `stabf` (`stable=0`, `unstable=1`) |
| 출력 | 선형 1개 | sigmoid 확률 1개 |
| 손실 | MSE | BCE |
| 판정 | 예측 `stab > 0` | 확률 `>= 0.5` |

입력은 `tau1,tau2,tau3,tau4,p2,p3,p4,g1,g2,g3,g4`의 11개로 고정한다. `stab`, `stabf`는 목표 누출 방지를 위해, `p1`은 다른 전력 변수로 복원되는 중복 정보이므로 제외한다. 회귀 목표는 스케일링하지 않는다.

## 사전 가설

- H1: 직접 이진 분류하는 모델 B의 판정 정확도가 더 높을 것이다. BCE가 과제의 판정 목표를 직접 최적화하기 때문이다.
- H2: 비교하는 네 optimizer 중 Adam이 가장 유망할 것이다. 적응적 학습률이 서로 다른 입력 방향의 최적화를 안정화할 것으로 예상하기 때문이다.
- H3: Adam에서는 학습률 0.001이 0.01보다 안정적이고 검증 정확도도 높을 것이다. 0.01은 이 작은 MLP에 과도해 진동할 가능성이 있다고 보기 때문이다.

H3의 두 설정을 모두 실제 평가하지 못하면 미검증으로 보고한다. 테스트 데이터는 모든 선택이 끝난 뒤 한 번 평가하고, 테스트 결과로 모델·학습률·임계값·epoch를 바꾸지 않는다.

## 고정 규칙

- 개발/테스트: 8000/2000, 층화, seed 42
- 목표 2 학습/검증: 6400/1600, 층화, seed 42
- 목표 2: 11-64-32-1, Adam 0.001, batch 64, 50 epoch, 두 모델 동일 초기 은닉 가중치와 배치 순서
- 목표 3: S01-S12만 허용. 학습 호출 직전 카운터를 영구 로그에 기록하고 13번째 호출을 차단
- 탐색: 최대 100 epoch, patience 15, 검증 정확도 우선/동률 시 loss로 checkpoint 선택
- 후보 순위: 검증 정확도, balanced accuracy, unstable recall, 실행 번호
- 최종 선택: 동일한 2-fold 평가 평균 정확도, balanced accuracy, recall, 기존 후보 번호 순
