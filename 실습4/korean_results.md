# 실습 4 실행 결과 해설

## 핵심 결과

- 목표 2의 50 epoch 검증 기준으로 선택한 문제 유형: **regression**
- 목표 3에서 선택한 설정: **RMSprop, learning rate 0.003, 42 epoch**
- 목표 3 실제 학습 호출: **12/12회**
- 최종 테스트 정확도: **0.9625**, balanced accuracy 0.9658, unstable F1 0.9701
- 목표 2 테스트 정확도: 회귀 0.9695, 직접 분류 0.9600
- 항상 unstable을 예측하는 기준선 정확도: **0.6380**. 최종 모델은 실제 unstable 1,276개 중 59개(4.62%)를 stable로 오판정했다.
- paired bootstrap 정확도 차이(분류-회귀): -0.0095, 95% CI [-0.0185, -0.0005]

## 가설 회고

- H1: not_supported. 직접 분류의 테스트 정확도가 회귀보다 높은지로 판정했다.
- H2: not_supported. 첫 4회 대표 학습률 비교 우승 optimizer로 판정했다.
- H3: untested. Adam 0.001과 0.01을 모두 평가했을 때만 판정했다.

## 해석 주의점

`stab`은 분류 입력에 쓰면 정답과 사실상 같은 정보를 주는 누출이므로 제외했다. `p1`은 `-(p2+p3+p4)`로 복원되는 중복 정보라 제외했지만, 제거가 반드시 성능 향상을 뜻하지는 않는다. 목표 2의 MSE와 BCE 절댓값은 척도가 달라 직접 비교하지 않았다. 2-fold 표준편차는 정밀한 신뢰도 추정이 아니며, 후보 선택에도 개발 데이터를 사용했으므로 최종 일반화 평가는 테스트 결과가 담당한다. 최종 모델은 8,000개, 목표 2 모델은 6,400개로 학습했으므로 향상을 optimizer 효과만으로 돌릴 수 없다. bootstrap은 고정된 모델과 테스트 표본의 불확실성만 반영하며 학습 seed 변동은 포함하지 않는다.

## 탐색 비용과 trade-off

적응형 4+3+4+1은 optimizer 폭, 우승 optimizer의 학습률 정밀화, 상위 2개에 대한 제한적 fold 신뢰도 확인을 배분했다. 첫 단계에서 optimizer별 학습률이 하나뿐이라 다른 학습률에서 강한 optimizer를 놓칠 수 있다. 따라서 결과는 전역 최적이 아니라 **주어진 예산과 후보에서 선택한 조합**이다. 목표 3 측정 학습 시간 합은 25.3초다. 고정 예시 학습률 5개 `[0.0001,0.001,0.003,0.01,0.1]`의 전수 3-fold는 60회, 최종 재학습 포함 61회다. 표본 수와 epoch를 반영한 수정 추정은 약 103.5초다. 실측 탐색 평균 69.2 epoch, fold당 실제 학습 약 4,267개·내부 검증 약 1,067개, 60회 학습 및 S12 실측 재학습 시간을 가정했다. 25/100 epoch 시나리오는 각각 38.7/148.7초다. 이는 신뢰구간이 아니며 fold 평가·전체 작업 부대비용은 제외했다. optimizer별 속도, 조기 종료, 장치에 따라 달라진다. 상세 산식은 `compute_cost.json`, 표는 `tables/compute_cost_scenarios.csv`에 있다.


## 추가 학습 없는 검수·보완 기록

- 기존 모델, 테스트 예측, 후보 순위, bootstrap, 사전 가설, 12회 카운터를 유지했다. 수정 전 파일은 `before_refinement/`에 보존했다.
- S12의 기존 epoch 기록에 있던 `val_loss`, `val_accuracy`는 실제로 개발용 학습 표본 1개의 점수였다. 독립 검증 점수가 아니므로 해당 열을 제거했다. 이는 checkpoint나 epoch 결정에 사용되지 않았고, 학습 가중치와 테스트 성능은 바뀌지 않았다.
- 목표 2 loss를 MSE/BCE 별도 축으로 표시하고 각 모델의 train/validation 곡선을 모두 제공했다. 지표는 epoch 종료 시점 가중치 기준이다.
- 대표 학습률 비교에서 RMSprop 0.001은 96.5000%, Adam 0.001은 96.4375%로 검증 표본 1개 차이였다. H2는 이번 제한된 비교에서 지지되지 않았지만, Adam의 일반적인 열등함을 입증하지 않는다.
- 목표 2 두 모델의 초기 가중치는 동일했다. 목표 3은 시작 seed는 고정했으나 순차적으로 모델을 생성해 후보마다 초기 가중치가 달랐다. optimizer 효과와 초기화 변동을 분리하지 못한다는 한계로 기록한다. 과거 실행을 동일 초기화 실험이라고 소급해서 설명하지 않는다.
- 최종 테스트 정확도 96.25%는 목표 2 회귀의 96.95%보다 낮다. 테스트 결과를 보고 모델을 교체하거나 설정을 변경하지 않았다.
- 실행 코드의 기존 결과 덮어쓰기·카운터 초기화를 차단했다. 향후 학습 함수 호출의 시작/종료/오류를 즉시 기록하도록 보완했지만, 과거에 해당 로그가 있었다고 주장하지 않는다.
